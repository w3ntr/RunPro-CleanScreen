## Features

* **Customizable HUD Toggles:** Hide or show individual UI elements (timers, speedometers, and etc.) on the fly.
* **One-Key Clean Screen:** Toggle all HUD elements instantly for cinematic screenshots or clean gameplay recording.
* **Persistent Settings (`.cfg`):** Automatically saves your UI preferences and keybinds to `UserData/MelonPreferences.cfg`.

---

## Hotkeys

* **`F5`** — Toggle Clean Screen / UI (Default)
* **`F6`** — Turn Off Hands

---

## Installation

1. Make sure **[MelonLoader](https://github.com/LavaGang/MelonLoader)** is installed for your game.
2. Download the latest `CleanScreen.dll` from the **Releases** section.
3. Place the `.dll` file into your game's `Mods` folder.
4. Launch the game!
